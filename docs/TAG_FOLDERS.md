# Tag folder profiles

The "Tag Summary" action opens a **tag folder** by switching to one of the
bundled read-only profiles below. The profiles and the `Profiles` list in the
built `manifest.json` are generated by `scripts/gen-profiles.mjs` (called by `scripts/build.mjs`) from
`src/tag-folders.json`, which the plugin also uses to pick the profile for the
pressed device:

| Profile             | Device                      | DeviceType | Model     | Grid  | Dials | Format | Tested |
| ------------------- | --------------------------- | ---------- | --------- | ----- | ----- | ------ | ------ |
| `TagFolderStandard` | Stream Deck (15)            | 0          | 20GAA9902 | 5 × 3 | –     | 2      | yes    |
| `TagFolderMini`     | Stream Deck Mini (6)        | 1          | 20GAI9901 | 3 × 2 | –     | 2      | no     |
| `TagFolderXL`       | Stream Deck XL (32)         | 2          | 20GAT9901 | 8 × 4 | –     | 2      | no     |
| `TagFolderPlus`     | Stream Deck + (8)           | 7          | 20GBD9901 | 4 × 2 | 4     | 3      | no     |
| `TagFolderNeo`      | Stream Deck Neo (8)         | 9          | 20GBJ9901 | 4 × 2 | –     | 2      | no     |
| `TagFolderGalleon`  | Corsair Galleon 100 SD (12) | 12         | GRETSCH   | 3 × 4 | 2     | 3      | no     |
| `TagFolderPlusXL`   | Stream Deck + XL (36)       | 13         | 20GBX9901 | 9 × 4 | 6     | 3      | yes    |

Model codes and grids are taken from the profiles Elgato bundles with the
Stream Deck app and its own plugins. Not supported: Stream Deck Studio (no
verified model code), Stream Deck Mobile and Virtual Stream Deck (the grid is
user-defined) and devices without displays (Pedal).

To support another device, add an entry to `src/tag-folders.json` (the device
type and grid size are logged by the plugin on `deviceDidConnect`; the model
code can be read from a profile of that device in the Stream Deck app's
`ProfilesV3` folder).

Each grid is filled with `com.kirkanos.kuma-glance.tag-slot` actions plus a
single `com.kirkanos.kuma-glance.tag-back` action in the bottom-right cell.
At runtime the plugin fills the slots (top-left → bottom-right) with the
monitors of the pressed tag; pressing a slot opens that monitor's Uptime Kuma
dashboard page in the browser. If the tag has more monitors than slots, the
last slot becomes a "Next" button that pages through the monitors.

## Important: validate the profile packages on real hardware

The profiles are generated, not exported from the Stream Deck app. Format 2 uses
the flat `Actions` map (keys are `"column,row"`); format 3 mirrors Elgato's own
bundled + XL profile. Neither can be verified in CI. **Before release, confirm the folders load correctly on the
target hardware.** If a profile does not switch/open correctly, regenerate it
the reliable way:

1. In the Stream Deck app, create a new profile for the target device.
2. Place the **Tag Slot** action on every key (top-left to bottom-right) and a
   **Tag Folder Back** action on the last key.
3. Export the profile, unpack it, and compare its structure with the
   output of `scripts/gen-profiles.mjs` and adjust the generator.
